# Adversarial finding evidence

One-off captures from the Phase-6 adversarial probing pass, backing the
findings in [`../adversarial-findings.md`](../adversarial-findings.md). Unlike
[`/defect-evidence/`](../../../../defect-evidence/) — which is regenerated by
`npm run evidence` from the automated `@known-defect` tests — these are manual
captures, because most Phase-6 findings are deliberately not automated (see the
ledger for why).

All captures use throwaway `qa.candidate+sb-*@example.com` accounts; none show
the real test account or any credential.

| File | Finding | Shows |
|---|---|---|
| `j-login-02-rate-limit-log.txt` | j-login-02 | Consecutive failed logins, all identical — no throttle or lockout. Now also covered by `login-rate-limit.spec.ts`. |
| `j-signup-onboard-6-01.png` | j-signup-onboard-03 | Questionnaire step 2 with a `Next` button and **no** `Back` button. |
| `j-signup-onboard-6-01-contrast-step3.png` | j-signup-onboard-03 | A later step for contrast — it *does* carry a `Back` button. |
